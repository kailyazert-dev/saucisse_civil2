Met à jour tous les fichiers CLAUDE.md du projet pour qu'ils reflètent fidèlement l'état actuel du code.

## Instructions

1. Repère tous les fichiers `CLAUDE.md` du projet (racine + sous-dossiers).
2. Pour chaque `CLAUDE.md` :
   a. Lis son contenu actuel.
   b. Lis les fichiers source Python du même dossier (et sous-dossiers immédiats si besoin).
   c. Identifie les écarts : classes renommées, méthodes ajoutées/supprimées, nouveaux fichiers, dossiers restructurés, comportements modifiés.
   d. Mets à jour le `CLAUDE.md` pour coller à la réalité — sans ajouter d'informations inutiles, sans supprimer de sections encore valides.
3. Respecte le style existant : tableaux Markdown pour les fichiers/classes, blocs de code pour les structures, français partout.
4. Ne touche pas aux sections encore exactes.
5. Une fois tous les fichiers mis à jour, liste un résumé des changements effectués (fichier par fichier).
